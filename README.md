# Washhup Car Wash Landing Page

A responsive static website built with HTML, CSS and vanilla JavaScript, inspired by the supplied Washhup design reference.

## Included files
- `index.html` — page structure and content
- `styles.css` — layout, responsive styling and colors
- `script.js` — mobile navigation and automatic footer year
- `assets/hero-car.jpg` — hero car image crop from the supplied reference
- `assets/why-car.jpg` — supporting car image crop from the supplied reference

## Mobile app link
All primary **Open Washhup** calls to action point to: https://www.washhup.com/signin

## Preview locally
Extract the ZIP and open `index.html` in a modern browser. Google Fonts requires an internet connection; the page layout and included image assets are local.

## Deploy
Upload `index.html`, `styles.css`, `script.js`, and the `assets` folder together to any static web host. Keep the relative paths unchanged.

## Note
Service descriptions and social icons are sample presentation content; verify them against Washhup's official services and social accounts before publishing.
